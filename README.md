# CodeAlpha Web Scraping and Data Analysis Project

## Project Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project demonstrates:

- Web Scraping using Python
- Data Cleaning using Pandas
- Data Analysis
- Data Visualization

Book data was scraped from the Books to Scrape website and analyzed to gain insights into book prices and ratings.

---

## Technologies Used

- Python
- Pandas
- Requests
- BeautifulSoup
- Matplotlib

## Features

### Web Scraping

Collected:

- Book Title
- Price
- Rating

from the Books to Scrape website.

### Data Cleaning

- Removed unnecessary symbols
- Converted ratings into numerical values

### Data Analysis

Generated:

- Average Book Price
- Highest Price
- Lowest Price
- Most Expensive Book
- Cheapest Book
- Rating Distribution
- Summary Statistics

### Data Visualization

Created:

- Rating Distribution Chart
- Top 10 Most Expensive Books Chart
